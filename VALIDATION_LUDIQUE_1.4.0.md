# Validation ludique — Moi Géomaticien 1.4.0

## Ajouts
- Mode rapide aléatoire : 5 questions.
- Mode rapide aléatoire : 10 questions.
- Sprint chronométré : 20 secondes par question.
- Missions quotidiennes : 3 objectifs.
- Système de 3 vies, réinitialisées chaque jour.
- Bonus de +50 XP après les trois missions quotidiennes.
- Vie récupérée après un quiz parfait.
- Animation de victoire sur les résultats.
- Messages humoristiques et emojis géomatiques.
- Aucun interrupteur de désactivation des rappels dans l'application.

## Notification
L'application programme automatiquement les rappels locaux toutes les 12 h. Android conserve cependant le contrôle final de l'autorisation système : un utilisateur peut bloquer les notifications dans les réglages du téléphone. L'application ne contourne pas ce contrôle système.
