# Publier la politique de confidentialité

La page prête à publier se trouve dans :

`web_legal/confidentialiteMg.html`

Pour obtenir l’adresse déjà intégrée à l’application :

1. ouvrez le projet du site `novateur.netlify.app` ;
2. placez `confidentialiteMg.html` à la racine du dossier publié ;
3. déployez le site ;
4. vérifiez que le bouton **Politique de confidentialité** de l’application ouvre bien la page.

L’interface de Moi Géomaticien n’affiche pas l’adresse technique : elle reste derrière le bouton dédié.
